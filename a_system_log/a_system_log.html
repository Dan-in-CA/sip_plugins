A System Log Plugin

This plugin send messages to the console on SIP events (System, Program, Station, Plugins).

The intent is to facilitate developpement of SIP core and plugins, and for system diagnostic.

${error_msg}
$(u"System events"): Start, reboot, config change, rain sensor and delay, midnight hello, ...
$(u"Program events"): Enable/disable, add, modify, delete, ...
$(u"Station events"): Scheduled (activated) / completed (desactivated) with related info.
$(u"Stations output"): Control command applied to stations relays (array).
$(u"Water events"): Water level, rain sensor and rain delay.
$(u"Plugins alarms and events"): General Plugin Alarm signal and this plugin event.
$(u"Mute Web server logs"): Mute periodic messages when SIP web page is accessed.
$(u"Prepend timestamp to messages"): Prepend ISO 8601 date and time with millisecond timestamp to console messages.
